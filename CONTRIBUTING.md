# Contribuer à SimulationForge

Installez `python -m pip install -e ".[dev]"`, développez sur une branche dédiée, puis exécutez `python -m pytest -q` et `python -m compileall -q apps packages`.

Chaque changement fonctionnel incrémente la version et conserve les tests historiques. Seeds, hypothèses, distributions et algorithmes restent explicites. Les résultats et qualifications sont recalculés côté serveur et ne constituent jamais une prédiction ou une certification.
